# Kaz Language Support for Lumina IDE & VS Code 🦅

Extensão oficial da linguagem de programação **Kaz** para **Lumina IDE** e **VS Code**.

## Recursos

- 🎨 **Syntax Highlighting Completo**: Reconhecimento de tipos primitivos (`int`, `float`, `string`, `bool`, etc.), estruturas (`struct`), coleções (`array[T]`), loops (`for..in`), operador ternário (`? :`), namespaces (`math.*`, `net.*`) e palavras-chave.
- ⚡ **Snippets Inteligentes**: Crie funções, structs, loops modernos e chamadas de rede digitando apenas atalhos (`main`, `fn`, `struct`, `forin`, `foridx`, `netping`, etc.).
- 🔧 **Configuração de Linguagem**: Suporte a auto-fechamento de chaves `{}`, colchetes `[]`, parênteses `()`, aspas `""` e comentários rápidos com `Ctrl+/` (`//` e `/* */`).

## Como Instalar

Execute o script de instalação automática na raiz do projeto:

```powershell
.\scripts\install_extension.ps1
```

A extensão será instalada instantaneamente na Lumina IDE (`~/.lumina-editor/extensions/kaz-language`) e no VS Code (`~/.vscode/extensions/kaz-language`).
